# Power BI Learning Library

An explanation-first Power BI learning guide built around the Code Institute retail exercise.

## Open the guide

The live guide is published at:

<https://tidyweb.github.io/power-bi-learning-library/>

The learner route starts with `docs/index.html` and moves through importing, cleaning, outliers, visuals, the data model, report building and publishing.

The repository also contains the three exercise CSV files and `RetailDashboard.pbix` so the links in the guide remain usable when the project is downloaded.

The guide uses original explanations, diagrams and examples. The Code Institute LMS remains the source for the assessed exercise sequence.
