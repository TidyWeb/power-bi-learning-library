02 / CLEAN AND STANDARDISE

Cleaning means making each value usable and understandable.

For every change, say what is wrong, what you will do, and how you will check the result.

POWER QUERYCLEANINGCHECK YOUR WORK

The Retail files show us real problems: the word NA in number columns, dates that need limiting, negative values, wrong types and values that need carrying down. A small text example shows trimming, splitting at a pipe and dealing with an uncategorised item.

A simple order for cleaning

1

Look

Use the profile to find the problem before touching a button.

2

Make values consistent

Trim spaces and use the same date, label and number format.

3

Decide what values mean

Keep empty, missing, zero, error and unknown separate until you know what they mean.

4

Check the result

Look again at the values, row count, dates and what one row describes.

Three rules that stop bad cleaning

A

Trim before matching

Spaces at the start or end can make two labels look the same but behave differently. Trim first.

B

Check before correcting

A negative Markdown value may be wrong; a negative temperature may be perfectly normal. Look at the column before changing it.

C

Write down Fill Down

Fill Down copies the last value into the rows below it. Use it only when the order of the rows makes that sensible.

Check your understanding before moving to the model
  1. Why is null not automatically the same as zero?
  2. Why should you inspect a suspicious negative value before replacing it?
  3. How would you check that splitting and trimming kept the right rows?

Answer: say what the value means, write the rule you used, and name the check that would show whether the rule worked.

Code Institute LMS exercise: clean the Retail queries

Now apply the general behaviour to the actual LMS inputs. In Power BI choose Home → Transform data, select Features data set, and keep the applied steps visible as an audit trail.

Features data set — the named operations

  1. Filter Date to on or after 01/11/2011, as the practice task specifies.
  2. Replace literal NA with null in Markdown1–Markdown5, then set those fields, CPI and Unemployment to Decimal Number.
  3. Fill Down CPI and Unemployment only after checking that the row order supports that assumption.
  4. Decide and record how remaining Markdown nulls are treated; do not silently call them zero.
  5. Trim text where the profile shows whitespace, then Close & Apply.
Use the raw input: Features data set.csv.

Transfer the reasoning to Sales
