START HERE / BEFORE YOU BUILD A CHART

Power BI begins before the chart.

A client asks for help. You receive one or more data files. They may be tidy, messy or incomplete. Before you build a chart, find out what the files contain and what they can honestly tell you.

START HEREORIENTATION

This library takes you through the work in order: understand the request, inspect the files, clean the values, connect the tables, build the calculations and make the charts. The files and the question may change; the way you check your work stays the same.

What does one row actually mean?

Every table has many columns. When we ask “what does one row describe?”, we are not asking you to list every column. We are asking what the row is mainly about. The other columns give details about that one record.

Read one Sales row

StoreDeptDateWeekly_SalesIsHoliday
1105/02/201024,924.50FALSE

This row is about: the sales for Department 1 in Store 1 for the week ending 5 February 2010.

Weekly_Sales and IsHoliday are important. They describe this sales record. They are not part of the short phrase that identifies which record it is.

Use a short sentence

Sales: one row tells us about one department in one store for one week.

Features: one row tells us about one store on one date. The other columns describe conditions such as temperature, fuel price and markdowns.

Stores: one row tells us about one store. The other columns describe it, such as its type and size.

Why this matters: before you add values or link tables, know what each row is about. Otherwise Power BI can count the same value more than once.

Keep these five parts separate

1

The request

What the client wants to know or decide.

2

The question

The more exact question you can ask after looking at the files.

3

The result

What the prepared data actually shows.

4

Your explanation

What you think the result might mean.

5

The next step

What someone can reasonably do or investigate next.

The first four checks

B

Understand the request

What does the client need to know, decide or monitor?

S

Check the files

What files arrived, where did they come from and what do they cover?

P

Check the columns

What type of value is in each column? Which values are empty, repeated or wrong?

!

Stop if you are unsure

Do not build a chart until you can explain what its numbers mean.

How to work through every page

For each task

  1. Look at what is actually there.
  2. Decide what it means.
  3. Change it for a stated reason.
  4. Check that the result is still right.

If a result looks wrong

Stop and go back to the last step you can no longer explain: the file, the values, the cleaning step, the table link or the calculation.

Keep this in mind: a chart is only as good as the checks behind it.
